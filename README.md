## Overview

**Zettask** is a minimalist daily task manager and planner designed to help you capture tasks, organize priorities, and stay consistent without visual clutter. Built with an **offline-first** architecture, Zettask launches instantly and works reliably with or without an internet connection.

## Key Features

- **Distraction-Free Task Management** — Create tasks in seconds with due dates, priorities, subtasks, notes, and tags.
- **Timeline & Project Views** — Plan your day chronologically in Timeline mode or group tasks into structured projects.
- **Timely Reminders** — Schedule local notifications so important deadlines never slip through the cracks.
- **Productivity Insights** — Track daily completion rates and consistency streaks with clean, readable statistics.
- **Android Home Screen Widgets** — View and check off upcoming tasks directly from your home screen.
- **Light, Dark & AMOLED Pure Black** — Adaptive theming with true `#000000` AMOLED black and 5 curated accent colors (`Monochrome`, `Sage`, `Indigo`, `Terracotta`, `Amber`).
- **Offline-First & Private** — Data is stored locally on your device first with zero forced sign-in.
- **Custom Lightweight Motion** — Pure Flutter vector onboarding illustrations and custom loading indicators built without heavy third-party animation dependencies.

## Download & Installation (Beta)

Zettask is currently in public beta prior to its Google Play Store release.

1. Open the [GitHub Releases](https://github.com/Zetheron/Zettask/releases/latest) page.
2. Download the latest **`app-release.apk`** from the **Assets** section.
3. Open the downloaded file on your Android device and allow *"Install unknown apps"* if prompted.

## Tech Stack

- **Framework:** Flutter (Dart)
- **Local Storage:** Offline-first local persistence & `SharedPreferences`
- **UI & Motion:** Material 3 foundation with custom `CustomPainter` vector graphics and adaptive theming
- **Localization:** Multi-language support via Flutter `gen-l10n` (`.arb`)
- **Quality Assurance:** Automated unit & widget test suite (70+ passing tests)
